Important limitations

GPS permission help: Android Settings → Apps → GeoBearing AI (or Chrome) → Permissions → Location → Allow while using the app; enable Use precise location. In Chrome also check ⋮ → Settings → Site settings → Location and allow this website. Turn on the phone Location quick setting. If permission was previously denied, change it in Settings before retrying. GPS requires HTTPS (except localhost); opening a downloaded HTML file or an unsupported preview may block it. Test outdoors and keep the app foregrounded during tracking.

Distance is a spherical great-circle approximation using a mean Earth radius. Bearings are initial bearings. Coordinate input range is latitude −90…90 and longitude −180…180. Use a verified magnetic declination value; it changes with location and date.

Privacy

This prototype performs calculations in your browser and does not send coordinates to a server. Saved records use local storage where supported. Avoid saving sensitive site coordinates on a shared device.
